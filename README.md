# marco-portfolio

Personal portfolio site — AI governance, technology policy, and governance design.

Static site deployed via GitHub Pages. No build step, no framework.

## Local dev

Open `index.html` in a browser, or:

```
npx serve .
```

## Structure

Single-page site with anchor-linked sections:

- About
- CV (interactive accordion)
- Writing
- Projects (hidden until content ready)
- Contact
